Before you start

  • An administrator has set MCP_API_KEY on the server (see above if not).
  • The server must be reachable from wherever Claude runs — e.g. from your laptop over the company network, not just from the server itself.

1. Your connection details

Server URL {{ mcpUrl }}
Header X-MCP-Key: {{ displayKey() }}

Machine clients can't follow a browser sign-in redirect, so the MCP endpoint uses this shared secret instead of your session cookie. This is your organization's live key, shown to you because you're signed in — see the security note below.

2. Add the configuration

Both Claude Desktop and Claude Code use the same JSON shape. Your key is already filled in below — copy and paste it as-is. 

{{ configSnippet() }}
desktop_windows Claude Desktop

Add the block above to the mcpServers config file:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
terminal Claude Code

Add the same block to a .mcp.json file in your project root (or your user-level Claude Code config, to make it available everywhere).

Other MCP-compatible clients (including Claude.ai's own connector settings, where available) accept the same server URL and header — consult that client's own documentation for exactly where to enter them.

3. Restart and verify

Restart the client so it picks up the new configuration, then just ask it something — see the examples below.

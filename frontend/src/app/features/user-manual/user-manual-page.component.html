Overview

This tool tracks the systems Tidalis has delivered — Maritime Control, Port Control and similar installations — so they can be reused as sales references, and the commercial contracts (deals) behind them.

A System is the thing that was actually built and delivered: its scope, location, modules, contacts and documents. A Contract is a commercial record that points back to the System it belongs to. One system can have several contracts linked to it (an initial implementation plus later maintenance renewals, for example). In case a support & maintenance contract is renewed, a new contract shall be created to reflect the updated information.

Both live in sortable, filterable grids with a slide-over detail panel for viewing and editing. Everything you see is also plotted on the World Map, and every change is recorded in the Audit Trail.

Systems

Systems in the top navigation opens the systems grid. Use the floating filter row under each column header to search, and click a column header to sort (columns without a sort arrow are derived/summary columns and can't be sorted). The Columns button lets you show or hide optional columns — your choice, along with column order and width, is remembered in this browser. Inside that same menu, Reset puts every column back to its shipped default — visible or hidden, order and width — and forgets whatever was remembered, in case things get into a state you no longer want.

Click any row to open it read-only in the detail panel on the right; click Edit there to make changes, or use New System above the grid to create one. A tab with an invalid or missing required field shows a small red dot on its label so you can find it quickly.

Detail panel tabs

  • General — name, UN/LOCODE, type, country, tags.
  • Scope & Description — scope, products and description text.
  • Ports & Locations — every UN/LOCODE port the system serves besides its own location.
  • Modules & Subsystems — the named modules delivered (see below) and free-text subsystems/interfaces.
  • People & Contacts — point of contact details and the people involved.
  • URLs — links (e.g. product pages, documentation) grouped by type.
  • Documents — files attached to the system, available once it's been saved once.

Picking the country from a UN/LOCODE

Picking a UN/LOCODE in the General tab fills the Country field in automatically from that location's own country. Country stays a normal, editable field — pick a different one yourself if the system's country genuinely differs from where it's installed.

Modules

Modules are picked from the shared list managed under Reference Data, not typed freely. A system must have at least one module.

When nothing is selected yet, a dropdown with checkboxes is shown directly so you can pick right away. Once at least one module is selected, the field collapses to a plain alphabetical list — much easier to scan than a long comma-separated line once a system carries ten or more modules — with a small pencil button next to it. Click the pencil to reopen the picker and change the selection; it collapses back to the list once you click away. The grid's own Modules column (opt-in via Columns) shows the same alphabetical list, growing the row's height to fit however many are assigned.

Showing or hiding a system on the World Map

The pinned Map column on the far left of the grid is a per-user preference, not a shared setting — checking or unchecking a row's box shows or hides that one system on your World Map, in this browser, right away. It has no effect on what colleagues see, and doesn't need saving.

The checkbox in that column's header is a bulk "select all" — it shows or hides every row currently passing your grid filters in one click. It's tri-state: ticked means every filtered row is shown, empty means every filtered row is hidden, and a dash means it's a mix. Filter the grid down first (e.g. to one country or product line) if you only want to bulk-toggle a subset rather than everything.

This selection is entirely separate from the grid's own filters, so it's worth remembering: a system left checked stays on your World Map even while a search or column filter is currently hiding its row from the grid. Filtering only changes what the grid displays right now — it never changes what's checked. Clear your filters if a system seems to be missing from the grid but you know it's still plotted on the map.

Contracts

Contracts works the same way as the Systems grid — floating filters, sortable columns, a Columns menu, click a row to view it, Edit to change it. Every contract links back to exactly one System, shown by name in the grid's System column and in the detail panel title.

Detail panel tabs

  • General — contract number, the linked System (type a few letters of its name to search and pick it — the same live lookup used for a system's own UN/LOCODE), award/completion dates, implementation and maintenance pricing, currency, contract type, tags and the Pipedrive deal number.
  • Notes — free text, in this order: Implementation details first, New developments below it.
  • URLs — links grouped by type, same as on a System.
  • Documents — files attached to the contract, available once it's been saved once.

World Map

Plots every system on a real nautical base map (water and coastline only — no navigational chart data), so it stays fast and uncluttered at a glance.

  • Theme — the sun/moon button in the map's corner switches between a light and dark base map. Dark is the default.
  • Colour theme — the palette button next to it lets you pick which named base-map style is used for light mode and which is used for dark mode, independently (e.g. ECDIS Day, ECDIS Night, Dark Modern). The list is read live from the tile server, so a style added there shows up here too, with no update needed. Your choice is remembered in this browser only.
  • Green markers mark a system's own location; a number inside a marker means several systems sit at the same spot — hover to fan them out into individual, clickable dots.
  • Show ports — the locations toggle additionally plots every port a system references, in a cream colour. Once shown, a system's own green marker gives way to its port marker(s) wherever it has any, so the same system is never shown twice at the same place; a system with no ports of its own keeps its marker, just recoloured to match the port layer.
  • Click any single marker to open that system directly; click a cluster's fanned- out dot the same way.
  • Full screen — the expand button hides the navbar, footer and page padding so only the map itself fills the screen: handy for a clean screenshot to drop into a presentation or document. A small close button sits bottom-centre to leave it again (or press Esc).
  • What you see here follows the Map column choices made in the Systems grid, for your browser only.

Reference Data

Reference Data manages the shared lookup tables that back dropdowns and tags everywhere else in the app. Open a tile to add, rename or delete an entry — a value still referenced by a system or contract can't be deleted until nothing uses it any more.

  • Countries and Currencies — standard reference lists.
  • UN/LOCODEs — ports and locations, each with coordinates, used for a system's own location and for its ports.
  • Modules — the named modules a system can be built from (see Systems).
  • Tags — coloured labels usable on both systems and contracts.
  • Document Types and URL Types — the categories offered when attaching a document or a link.

Audit Trail

Audit Trail lists every create, update and delete, for either Systems or Contracts (Systems by default) — switch between the two with the toggle at the top. Open an entry to see exactly which fields changed and their before/after values.

Timestamps show in your own browser's local time by default; use the Local / UTC toggle next to it if you'd rather compare entries in UTC — colleagues in other timezones can do the same independently, since it's remembered per browser, not shared.

Connect Claude

Connect Claude exposes this data over MCP (Model Context Protocol), so Claude Desktop, Claude Code or any other MCP-compatible client can answer questions about systems, contracts, ports and pricing directly — without anyone copying data into a chat by hand. The page there walks through the connection details step by step.

Tips & FAQ

  • Nothing is saved until you click Save — Cancel discards your edits and reverts to the last saved version.
  • A red dot on a tab label means a required field on that tab is missing or invalid.
  • Grid column order, visibility, width and your filters are remembered per browser, not shared with colleagues.
  • The Systems grid's Map column, the World Map's "show ports" toggle and the Audit Trail's Local/UTC timestamp choice are all per-browser preferences — they don't affect what anyone else sees.
  • Deleting a system or contract removes it from the grid and the map immediately — if you delete one by mistake, contact an administrator right away rather than recreating it from scratch.
